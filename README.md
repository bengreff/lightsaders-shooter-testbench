# Lightsaders BIOBUZZ shooter testbench

An interactive simulation of our FTC team's proposed turret shooter for the 2026-27 BIOBUZZ season: a belted Hogback
flywheel under a concentric, servo-swung hood, fed straight up the turret's bore.

**Open the app:** https://bengreff.github.io/lightsaders-shooter-testbench/

Runs in the browser: MuJoCo (WebAssembly) for the physics, three.js for the drawing. Desktop Chrome or Edge recommended.
The first load downloads ~25 MB (the physics engine and the meshes).

This repository is generated: it is a published copy of the testbench, built from the team's private development
repository; changes are made there and re-published.
