# Lightsaders turret testbench

The BIOBUZZ turret, lift and cell, simulated in the browser (MuJoCo WebAssembly + three.js).
Open: https://bengreff.github.io/lightsaders-shooter-testbench/

Built from the team's code-CAD (`BIOBUZZ/sim/mechanism/turret/` in lightsadersCode) by `BIOBUZZ/web/shooter/tools/publish.py`.
